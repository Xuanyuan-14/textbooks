# 课内训练 · 跨会话学习档案

此目录是 ChatGPT 各会话共用的**学习进度档案**，不是教材正文。教材位于本仓库各书对应目录。

## 如何使用（给任何新会话里的 AI）

1. 通过已连接的 GitHub 读取本目录的 `README.md`、`overview.md`、`review-queue.md`，必要时看 `sessions.md` 最近几条。
2. 根据 `overview.md` 的**课堂进度**确定当前课程范围，根据**实际掌握**和 `review-queue.md` 选择题目；两者不可混同。
3. 每次布置教材题之前，读取最新版教材该章节原文，核对题号、原题内容以及相应插图。注意 OCR 可能误认公式、题号和图题；遇到歧义先核验，不能把猜测当作原题。
4. 每次只呈现一题，先让学生自己思考，优先以提问、提示和纠错引导；学生尝试前不直接给完整答案。对同类题再做一次独立复测。
5. **仅在获得实际作答或明确完成反馈后**，更新 `overview.md` 的掌握状态、`review-queue.md` 的复习安排，并在 `sessions.md` 追加简要记录。未答、未确认、计划已发送都不等于完成。
6. 写回 GitHub 时须先读取当前文件及 SHA，再使用更新操作；发生冲突时重新读取、合并后再写，避免覆盖别的会话记录。若当前会话没有 GitHub 写入权限，应明确告诉学生进度尚未同步，不可宣称已保存。

## 教材基准

- **数学物理方法**：`数学物理方法（第四版）[十二五国家级规划教材] (姚端正 周国全 贾俊基)`；这是与学校相同的版本。请勿沿用此前钟玉泉或顾樵版的题号。
- **电路理论**：`电路分析第二版 (张小梅 刘岚 李政颖)`。
- **模拟电子技术**：`电子技术基础模拟部分（第七版）(康华光)`。

各章正文在相应 `chapters/<章目录>/README.md`，图片在同章 `images/`。必要时可经 GitHub `fetch_file` 以 base64 获取图片并进行视觉检查；仅看到路径不等于看懂电路图。书中还可能有参考答案，做题前不要泄露。

## 训练节奏

- 目标：**快速补齐旧知识 → 追上课堂 → 跟随课堂同步练习**；不强制补看全部课本，不以听懂讲解代替独立做题。
- 工作日每天**上限**为两个约 35 分钟的课内单元（总计最多 70 分钟），不占用课外额外做大量作业；没有时间就顺延，**不积压欠账**。
- 每单元标准约 **2 道原题（含小问或复做）**，必要时缩减题量，按 5 分钟回顾、10 分钟尝试、12 分钟引导、5 分钟复测、3 分钟记录的大致节奏执行。
- 暂定轮换：周一数学物理+电路；周二模电+数学物理；周三电路+模电；周四数学物理+电路；周五模电+错题复测。具体执行服从学校实际课表、上次未做完内容和最新课堂进度。
- 正确且不依赖提示地完成两道同类题（最好隔一次学习再次复测），才可标记为“已掌握”；只会跟着提示做则标记“需引导”；未检验统一标记“待诊断”。
- 若新进度与本档案冲突，以学生最新明确报告为准，记录更新日期。

## 文件分工

- `overview.md`：三科课堂进度、能力诊断、最近任务和下一步。
- `review-queue.md`：错题/薄弱点、待复习题和复测计划；**候选弱点不等于已核实的错题**。
- `sessions.md`：每次真实学习回合的简短日志，未开始的安排不记作已完成。

初始化于 2026-10-21。这个目录通过 GitHub 共享，**不会随着聊天内容自动更新**；需要具备权限的会话实际写回。
