解：自发辐射是处于高能级的原子自发向低能级跃迁发出的光。

受激辐射是在外界辐射场控制下进行的发光过程，受激辐射发出的光与入射辐射场具有相同的频率、相位、偏振化方向和传播方向。激光器的发出的光即有自发辐射光又有受激辐射光，但受激辐射占优势。

正常情况下，处于热平衡态的物体高能级原子数远小于低能级原子数，物质吸收光子数目大于放出光子数目，无法实现光放大。要实现光放大，必须使高能级上的原子数大于低能级的原子数，即实现粒子数反转。产生激光除了有能实现粒子数反转的工作物质外还需要光振荡满足阈值的条件。

## 4. 比较受激辐射和自发辐射的特点。从辐射的机理来看普通光源和激光光源的发光有何不同？

解：①自发辐射：处于高能态的原子由于不稳定而自发的跃迁到低能态，同时辐射出光子。它是一种随机的过程。各原子的辐射完全是自发地独立进行，各原子辐射的光的频率、传播方向、相位、偏振态无确定关系，为非相干光。

②受激辐射：处于高能态的原子，若受到入射光等的激励，会从高能态跃迁到低能态，同时辐射一个与入射光子的频率、传播方向、相位、偏振态完全相同的光子。该过程是受激辐射产生。产生的光是相干光。

## 5. 从能带结构来看，导体、半导体和绝缘体有什么不同？

①导体能带的特征：（1）价带是未满带，电子很容易在导带中从低能级向高能级跃迁。（2）价带是满带，但满带与空带相重叠，电子很容易从满带跃迁到空带中而导电。（3）价带是未满带，而它又与相邻的空带重叠。

②绝缘体能带的特征：（1）只有满带和空带；（2）满带和空带之间有较宽的禁带。由于满带中的电子不参与导电，一般外加电场又不足以将满带中的电子激发到空带，此类晶体导电性极差。

③半导体能带的特征：只有满带和空带，与绝缘体的能带相似，差别在于禁带宽度不同，半导体的禁带宽度一般较小，在2eV以下。

## 6. 半导体的导电机制是什么？适当掺入杂质和加热都能使半导体的电导率增加，这两种情况有什么不同？

解： 半导体能带的特点：只有满带和空带，与绝缘体的能带相似，差别在于禁带宽度不同，半导体的禁带宽度一般较小，在2eV以下。

半导体导电能力介于导体与绝缘体之间的晶体。

半导体分为：本征半导体和杂质半导体

本征半导体：纯净无杂质的半导体。

杂质半导体：在纯净半导体中掺入微量其它元素的原子（杂质），杂质能级介于半导体的两个能级之间，使电子更容易在杂质与半导体之间移动，半导体的导电能力将显著增强。

此外，加热一般也可使电子运动速度加快，从而使导电率增加。
